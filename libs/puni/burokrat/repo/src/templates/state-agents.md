# {{name}}

The system-state repository of {{name}}: what {{name}} is now, under the
rules the `puni` CLI enforces.

## Working here

- The gate is `puni burokrat check`, run here, and
  `puni burokrat check --repo system-records` for the records.
- Unsure where something lives? `puni burokrat wiki map` prints the map
  from a task to the file to read first.
- Records live in <{{recordsUrl}}>, cloned beside this repository as
  `../{{name}}-records`; its `AGENTS.md` says how to file one. File one when
  the task asks, or when you decide something this repository and its commit
  messages cannot carry. Read a record only when a task names it.
