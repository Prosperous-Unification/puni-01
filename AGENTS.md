# puni-01

The PUNI platform: the `puni` CLI and the rules it enforces on every
repository it governs.

## Finding things

- Start at `wiki/index/index.md`. It maps a task to the one file to read.
- History lives in the records repository,
  <https://github.com/Prosperous-Unification/puni-01-records>, checked out
  beside this one as `../puni-01-records`. Read it only when a task names a
  record. This is the only file that links there.

## Rules

1. **State, not history.** This repository holds the system as it is. How it
   got there belongs in the records repository.
2. **One home for every fact.** Knowledge lives with the thing it describes
   and is written once.
3. **Enforce, don't describe.** A rule a tool can check becomes a check, and a
   check that cannot fail is not a check.
4. **Evidence before claims.** Nothing works until fresh output shows it. Say
   what was not verified.
5. **Three roles.** Navigator decides, Dash does, Burokrat judges. Every piece
   of work and every command belongs to one of them.
6. **Everything earns its place.** Nothing is added ahead of a need. The owner
   decides what is needed.
